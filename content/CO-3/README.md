# CO-3 — Addressing, Routing and Internetworking

Course: Computer Networks and Network Programming (25CS2208E)

This folder contains six YAML parts aligned to CO-3 in the supplied course handout.

| Part | File | Main coverage |
|---|---|---|
| 01 | co3_01_ipv4-prefix-vlsm-ipv6.yaml | IPv4 prefixes, subnetting, VLSM, summarisation, IPv6 |
| 02 | co3_02_dhcp-relay-dns-troubleshooting.yaml | DHCPv4, relay, DNS zones, address troubleshooting |
| 03 | co3_03_control-data-plane-lpm-arp.yaml | Control/data planes, LPM, ARP, forwarding |
| 04 | co3_04_distance-vector-link-state-ospf.yaml | Distance-vector, count-to-infinity, SPF, OSPF convergence |
| 05 | co3_05_route-selection-convergence.yaml | Route selection, dual uplinks, failover |
| 06 | co3_06_nat-redundancy-bgp-overlays.yaml | NAT, first-hop redundancy, BGP, overlays and MTU |

Skilling experiments covered: 13–16. Lecture sessions covered: 9–12.
The course handout's design targets include 60% address-plan growth, OSPF convergence under five seconds, and dual-uplink failover without black-holing.
