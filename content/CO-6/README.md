# CO-6 — Predictability: Real-Time, Multicast and QoS

Structured learning files for Computer Networks and Network Programming (25CS2208E), aligned to CO-6 in the supplied course handout.

## Contents
1. Real-time communication and latency budgets: end-to-end delay, named path components and budget allocation.
2. Jitter, playout buffers and media bandwidth: delay variation, tail-sized buffers and media wire-rate calculations.
3. Queue disciplines: FIFO, priority queuing, fair queuing and their performance bounds.
4. DiffServ, policing and shaping: packet marking, traffic classes, media capacity and traffic conditioning.
5. Multicast, IGMP and PTP: multicast delivery, group membership and clock synchronization.
6. E-model and integrated performance validation: voice-quality estimation, p50/p99 distributions and sustained contention.
